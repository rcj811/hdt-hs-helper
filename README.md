# 爐石輔助 HsHelper

Hearthstone Deck Tracker（HDT）外掛 + 一鍵安裝程式。

## 安裝

到 [Actions](../../actions) 或 [Releases](../../releases) 下載 `HsHelper-Setup-x.y.z.exe`，執行即可：

- **電腦上還沒有 HDT** → 安裝程式會從官方網址下載 HDT 安裝檔並開啟，裝好後接著安裝外掛
- **已經有 HDT** → 自動略過，只安裝外掛

安裝完請重新啟動 HDT，到 **選項 → 追蹤器 → 外掛** 確認「爐石輔助 HsHelper」已啟用。

外掛位置：`%AppData%\HearthstoneDeckTracker\Plugins\HsHelper\HsHelper.dll`

## 自動出牌（v0.2，構築／休閒／練習模式）

> ⚠️ 自動出牌違反暴雪使用條款，可能被封號，請用分身帳號或練習模式。

- **F8**（或 HDT 選單「外掛 → 爐石輔助」）開始／停止，畫面中央會顯示「已啟動／已停止自動打牌」並發出提示音；爐石視窗不在最前面時會自動暫停
- 對戰結束後自動點掉勝利／失敗、經驗條、獎勵畫面，回到「對戰」或「練習」選牌畫面後自動按「開始」
  （正在配對中不會重按；HDT 選單「外掛 → 爐石輔助 → 對戰結束後自動下一場」可關閉）
- 擬人化：每個動作前隨機思考 0.5～2 秒，滑鼠平滑移動並帶隨機偏移
- 換牌：留 3 費以下；後手且有低費牌時多留一張 4 費
- 每一步都模擬整個回合的出牌＋攻擊順序（深度 12、寬度 200），用評分函式挑最好的一條，只執行第一步後重新讀狀態
- 評分權重參考開源爐石 AI SilverFish（Hearthbuddy 核心）：自己 10 血以下重罰、對手 11 血以下壓血加分、高攻擊敵方手下加重威脅、剩餘法力扣分、下回合可能被斬殺大扣分
- 看不懂的卡牌效果用費用估值；需要目標但看不懂的牌會跳過；動作沒成功會取消並在本回合略過那張牌

### v0.4：策略升級與自動學習

參考 GitHub 與爐石 AI 競賽（IEEE CoG 2018–2020）的做法：

- **對手回合模擬**（SilverFish 的 EnemyTurnSimulator 概念）：候選路線會再模擬對手下回合反擊，避免「打完臉被反殺」
- **誰是打臉方**：比較雙方幾回合能打死對方，佔優時自動加重打臉
- **演化演算法調權重**（競賽中 EA 調評分函式的做法）：19 個權重在模擬器中自動調整，結果見 `tests/HsHelper.Tests/tune-result.txt`
- **從對局學習**：每場記錄對手職業、出過的牌、打臉速度、爆發、AOE 頻率與輸贏，存在 `%AppData%\HsHelper\learning.json`
  - 遇到相同／相似對手會參考這些紀錄（調整斬殺警戒、避免對 AOE 對手過度鋪場）
  - 「輸了才學」：對打得贏的對手維持原打法；對常輸的對手用 UCB1 輪流嘗試平衡／進攻／控場，保留勝率最好的
- **匯出／匯入學習資料**：HDT 選單「外掛 → 爐石輔助」。匯入時逐筆比對紀錄編號，已有的略過、沒有的加入
- **內建模擬器學習資料**：720 場模擬對局，第一次啟動自動匯入（同樣比對去重）

### v0.5：自動選套牌

- 開始下一場前，從遊戲記憶體讀出選套牌畫面這一頁的套牌（與 HDT 相同的 HearthMirror 來源）
- **AI 適合度**：依卡表算手下比例、平均費用、AI 看得懂的卡牌比例（發現、抉擇、奧秘、組合技等算複雜卡）
- **挑預估勝率最高的**：預估勝率 =（實戰勝場 + 適合度先驗 × 4）÷（實戰場數 + 4）；一直輸的套牌預估勝率會下降，自動換別副
- 點選後再讀一次「目前選中的套牌」確認，選錯會重點，3 次失敗就用目前的套牌
- 只在目前這一頁的套牌中挑（不會自動翻頁）；HDT 選單可關閉「自動選勝率最高的套牌」

### v0.6：新機制支援與偵測通知

- **組合（Assemble）**：讀遊戲記憶體知道選項與目前選擇，點選 → 確認選中 → 按「組合」→ 確認畫面關閉
- **發現／抉擇／黑暗之賜（Dark Gift）**：點擊位置改用 HDT RegionDrawer 的精確版面；點了沒反應會換一張，卡住會通知
- **新機制偵測通知**（畫面中央提示＋`%AppData%\HsHelper\notices.log`，HDT 選單「查看新機制通知…」）：
  - HDT 更新：版本變更、HearthMirror 新增遊戲讀取功能（通常代表新機制／新畫面）、卡牌資料庫新增遊戲標籤
  - 第一次遇到的玩法（遊戲類型／格式），並說明自動出牌是否支援
  - 第一次看到的卡牌粗體關鍵字
  - 自動出牌處理不了的選擇畫面

### v0.7：新機制報告（給 Claude）

HDT 選單「外掛 → 爐石輔助 → 匯出新機制報告（給 Claude）…」會產生一個 zip：

- `report.md`：依優先順序整理的待處理項目（卡住的畫面 → 打不出來的卡 → 新關鍵字 → HDT 新功能 → 新玩法），
  每項附卡牌資料（中英文名稱、英文敘述、遊戲標籤、AI 的理解）、出現次數、**出現時的勝率**、建議修改的檔案
- `report-data.json`：原始資料；修好的項目把 `Resolved` 設為 true
- `shots/`：出事當下的爐石畫面截圖（每項最多 3 張）
- `notices.log`、`hdt-log-excerpt.txt`：通知紀錄與相關 HDT log

把 zip 交給 Claude，就能直接依報告修改並加測試。

### 模擬測試

`tests/HsHelper.Tests` 是決策 AI 的模擬測試（情境測試、400 個隨機局面、新舊版對戰、學習功能、匯入匯出），
GitHub Actions 每次都會先跑，**沒全部通過就不會產出安裝檔**。結果在 Actions 頁面的摘要。

## 狀態面板

進入對戰後，遊戲畫面左側會顯示狀態面板：

- **對戰**：回合、雙方職業／生命／手牌數／牌庫數、場上手下與總攻擊
- **酒館戰棋**：生命、酒館等級、我方陣容（含星級）；戰鬥階段顯示對手英雄、酒館等級與陣容

HDT 選單「外掛」或外掛設定頁的按鈕可以顯示／隱藏面板。

## 開發

- `src/HsHelper/`：外掛原始碼（C#、.NET Framework 4.7.2）
  - `GameStateReader.cs`：從 HDT 讀取遊戲狀態（之後的決策模組也用這份資料）
  - `StatePanel.cs`：覆蓋層面板
- `installer/HsHelper.iss`：Inno Setup 安裝程式
- `scripts/fetch-hdt-refs.ps1`：編譯時從官方 HDT 發行版取出參考檔（不放進 repo）

推到 `main` 會自動編譯。要發布新版：改 `HsHelper.csproj` 的 `<Version>`，再到 Actions → Build → Run workflow 勾選「建立 GitHub Release」。
